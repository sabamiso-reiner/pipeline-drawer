記法リファレンス

座標は x = スロット（サイクル）、y = 行。行 k（1始まり）は y = k−1 〜 k の範囲。小数OK。プレビュー上でマウスを動かすと座標が下に出ます。

命令行：ラベル | 種類 | ステージ列（種類は省略可）

1 lw r1, 0(r2) | load   | IF ID EX MEM WB
2 （誤った経路） | wrong  | @1 IF ID {flush}
3              | normal | @2 IF {bubble}*2 ID EX ... WB
@nスロット n から開始
IFステージ（既定スタイル stage）
EX{hl}スタイル指定付きステージ
EX{#ff8800} / EX{red}その円柱だけ色を直接指定（凡例には出ない。暗い色なら文字は白）
{flush}ラベル無しの円柱
X*33回繰り返し
... / .「・・・」/「・」（連続する ... は1つにまとまる）
-空きスロット

定義・注釈

type 名前 fill=#d7e4bd text=#000 legend="ロード命令"左ラベル列の種類（四角の凡例）
style 名前 fill=#404040 text=#fff legend="フラッシュ"ステージの見た目（円柱の凡例）。組込: stage, flush, bubble, hl
set slotW=95 rowH=30.5 ...寸法・フォント等（下記）
vline 0 1 6縦の破線
vline 3 top="t1" bottom="検証終了" color=#c00000 size=20破線の上・下に文字（\n で改行。color は線と文字の色）
text x y "文字\n2行目" color=#f00 size=24 align=left|center|right border=#2e75b6 bold注釈テキスト（y は縦中心）
arrow x,y -> x,y -> x,y color=#4472c4 heads=end|start|both|none折れ線矢印
brace y1 y2 x "ラベル" color=#0070c0右側の括弧＋ラベル
legend x y / legend off凡例の位置（左上）
caption "図の説明"図の下のキャプション
// または行頭 #コメント
