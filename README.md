# Pipeline Drawer

テキストで書いた命令列から、プロセッサのパイプライン図（円柱のステージが並ぶ図）を描くツールです。
`pipeline-drawer.html` 1 ファイルだけで動き、インストールは不要です。

## 使い方

1. `pipeline-drawer.html` を Chrome / Edge でダブルクリックして開きます（Firefox でも動きますが、保存先の選択など一部の機能が簡易版になります）。
2. 左の入力欄に命令列を書くと、右に図がすぐ描かれます。
3. 「図を書き出し ▾」から PPTX / PNG / SVG で保存します。

> PPTX 書き出しはライブラリを CDN（jsdelivr）から読み込むため、インターネット接続が必要です。

## 画面の操作

| 場所 | 内容 |
|---|---|
| テンプレート… | 組み込みのサンプル（5 つ、削除不可）や、自分で保存したテンプレートを読み込みます。「＋ 今の内容をテンプレートとして保存…」「マイテンプレートを削除…」もここにあります。 |
| 入力テキストを開く / 保存 | 左の入力欄の内容を `.txt` で読み書きします。後で開けば続きから編集できます。 |
| 拡大 | プレビューの表示倍率（書き出しには影響しません）。 |
| 幅 / 高さ | ステージ 1 つの横幅（`slotW`）と 1 行の高さ（`rowH`）。動かすと入力欄の `set` 行が書き換わります。「既定に戻す」で既定値に戻ります。 |
| 図を書き出し ▾ | PPTX（PowerPoint で編集可能な図形として）/ PNG / SVG で保存、PNG をクリップボードにコピー。保存の 3 つは、Chrome / Edge では保存場所とファイル名を選べます（前回の書き出し先が最初に開きます。入力テキストの保存先とは別に覚えます。ほかのブラウザではファイル名だけ入力）。ファイル名の初期値は入力テキストの名前に合わせます（例：`pipeline.txt` → `pipeline.pptx`）。 |
| ？ 使い方 | 画面の各部分を順番に緑の枠で囲み、押すと何が起こるか・結果がどこに出るかを説明します（→ / Enter で次へ、← で戻る、Esc で閉じる）。 |

プレビュー上でマウスを動かすと、下のステータス欄にその位置の座標（x = スロット、y = 行）が出ます。`text` や `arrow` の位置決めに使ってください。

## 記法

座標は **x = スロット（サイクル）**、**y = 行** です。行 k（1 始まり）は y = k−1 〜 k の範囲です。小数も使えます。

### 命令行

```
ラベル | 種類 | ステージ列
```

種類は省略できます（`ラベル | ステージ列`）。

```
1 lw r1, 0(r2) | load   | IF ID EX MEM WB
2 （誤った経路） | wrong  | @1 IF ID {flush}
3              | normal | @2 IF {bubble}*2 ID EX ... WB
```

| 書き方 | 意味 |
|---|---|
| `@n` | スロット n から開始 |
| `IF` | ステージ（既定スタイル `stage`） |
| `EX{hl}` | スタイルを指定したステージ |
| `EX{#ff8800}` / `EX{red}` | その円柱だけ色を直接指定（凡例には出ない。暗い色なら文字は白） |
| `{flush}` | ラベル無しの円柱 |
| `X*3` | 3 回繰り返し |
| `...` / `.` | 「・・・」/「・」（連続する `...` は 1 つにまとまる） |
| `-` | 空きスロット |

色やスタイルを書きかけの状態（`EX{#f` など）でも行は消えず、その部分だけ既定の色で描かれ、エラー欄に警告が出ます。

### 定義・注釈

| 書き方 | 意味 |
|---|---|
| `type 名前 fill=#d7e4bd text=#000 legend="ロード命令"` | 左ラベル列の種類（四角の凡例） |
| `style 名前 fill=#404040 text=#fff legend="フラッシュ"` | ステージの見た目（円柱の凡例）。組み込み: `stage`, `flush`, `bubble`, `hl` |
| `set slotW=95 rowH=30.5 ...` | 寸法・フォントなど（下記） |
| `vline 0 1 6` | 縦の破線（ステージと重なる部分は隠れる） |
| `vline 3 top="t1" bottom="検証終了" color=#c00000 size=20` | 破線の上・下に文字（`\n` で改行。`color` は線と文字の色、`size` は文字の大きさ） |
| `text x y "文字\n2行目" color=#f00 size=24 align=left\|center\|right border=#2e75b6 bold` | 注釈テキスト（y は縦中心） |
| `arrow x,y -> x,y -> x,y color=#4472c4 heads=end\|start\|both\|none` | 折れ線矢印 |
| `brace y1 y2 x "ラベル" color=#0070c0` | 右側の括弧＋ラベル |
| `legend x y` / `legend off` | 凡例の位置（左上）/ 非表示 |
| `caption "図の説明"` | 図の下のキャプション |
| `//` または行頭 `#` | コメント |

### `set` のキー

| キー | 既定値 | 意味 |
|---|---|---|
| `slotW` | 95 | ステージ 1 つの横幅（px） |
| `rowH` | 30.5 | 1 行の高さ（px） |
| `labelW` | 230 | 命令名の枠の最小幅（長い名前は自動で広がる） |
| `labelGap` | 3 | 命令名の枠とステージの間隔 |
| `cylH` | 0.9 | 行の高さに対する円柱の高さの割合 |
| `cap` | 0.3 | 円柱の高さに対する端の楕円の幅の割合 |
| `fontSize` / `stageFontSize` / `legendSize` | 22 / 21 / 26 | 文字サイズ（命令名・ステージ・凡例） |
| `legendGap` | 1.3 | 凡例の行間（行の高さに対する倍率） |
| `font` / `stageFont` | メイリオ / Times New Roman | フォント |
| `stroke` / `strokeW` | #000000 / 1.2 | 線の色・太さ |
| `rowBorder` / `rowBorderW` | #1f3864 / 2 | 命令名の枠線の色・太さ |
| `axis` | cycle | 下の時間軸のラベル（`none` で非表示） |
| `labels` | on | `off` で左の命令名の列を非表示 |
| `slots` | 0 | 横のスロット数（0 なら自動） |
| `pad` | 12 | 図の周りの余白 |
| `pptx` | 4:3 | PPTX のスライド比（`4:3` / `16:9`） |
| `pptxX` / `pptxY` / `pptxW` | （自動） | PPTX 上の図の位置・幅（インチ） |

## データの保存場所

| もの | 保存場所 |
|---|---|
| 作業中の入力内容 | ブラウザの localStorage（`pipeline-drawer-src`）に自動保存 |
| マイテンプレート | ブラウザの localStorage（`pipeline-drawer-templates`） |
| 組み込みテンプレート | `pipeline-drawer.html` の中 |
| 入力テキスト・書き出した図 | 保存時に選んだファイル（入力テキストは `my-inputs/` がおすすめ） |

localStorage はブラウザの中にあり、ファイルとしては見えません。

- 同じブラウザなら、タブやブラウザを閉じても、PC を再起動しても残ります。
- Chrome / Edge では、HTML を直接開いたページ（`file://`）はすべて 1 つの localStorage を共有します。そのため `pipeline-drawer.html` を別のフォルダに移したり名前を変えたりしても、内容はそのまま引き継がれます。
- 逆に、`pipeline-drawer.html` のコピーが複数あると、作業中の内容とマイテンプレートを共有します。同時に開くと作業中の内容を上書きし合うので注意してください。
- 別のブラウザや別の PC、シークレットウィンドウでは引き継がれません。ブラウザのサイトデータ（Cookie とサイトデータ）を削除すると消えます。

残したいものは「入力テキストを保存」で `.txt` にしてください。

`my-inputs/` は、自分の作業用の入力テキストを置くためのフォルダです。中身は `.gitignore` で除外されるので、git の管理には入りません。Chrome / Edge では、「入力テキストを保存 / 開く」は前回入力テキストを保存・読み込みしたフォルダで開くので、一度このフォルダを使えば次からはここが最初に開きます（図の書き出し先は別に覚えます）。

`.txt` に保存していない変更があると、タブ名に「●」が付き、タブを閉じる・再読み込みするときに確認が出ます。

## ファイル構成

```
pipeline-drawer.html   ツール本体（HTML / CSS / JavaScript すべて）
README.md              このファイル
my-inputs/             自分の作業用の入力テキストの置き場所（中身は git 管理外）
.gitignore             書き出した図（*.pptx, *.png, *.svg）と my-inputs/ の中身を除外
```
